# Creature Spawner 1.0.0

A mod for **Hollow Knight** that lets you **spawn any creature or boss anywhere in the game**.

Press **Ctrl** to open the panel, pick a creature, and it appears next to you, ready to fight.

## How to use

1. In game, press **Ctrl** to open (or close) the panel.
2. Search for the creature by name. Search also works with the name in Portuguese.
3. Click its name to spawn it.

## Change the key

Don't like Ctrl? Change the key from the game's main menu:
**Mods → Creature Spawner → Tecla do Menu** (the menu key option).

## Requirements

- Hollow Knight (Steam)
- Modding API installed

## Installation

Put the `CreatureSpawner` folder (with `CreatureSpawner.dll` inside) in:

`Hollow Knight\hollow_knight_Data\Managed\Mods\`

## Good to know

- **The game takes longer to start.** The mod loads all creatures at once on startup. This only happens once per session.
- Bosses were adapted to fight outside their original room, but some details may differ from the base game.
- If you find a bug, it is most likely tied to one specific creature. Please note its name and what happened.

# Creature Spawner 1.0.0

Um mod para **Hollow Knight** que deixa você **spawnar qualquer criatura ou chefe em qualquer lugar do jogo**.

Aperte **Ctrl** para abrir o painel, escolha a criatura e ela aparece perto de você, pronta para lutar.

## Como usar

1. Dentro do jogo, aperte **Ctrl** para abrir (ou fechar) o painel.
2. Procure a criatura pelo nome. A busca também funciona com o nome em português.
3. Clique no nome dela para spawnar.

## Mudar a tecla

Não gosta do Ctrl? Troque a tecla no menu principal do jogo:
**Mods → Creature Spawner → Tecla do Menu**.

## Requisitos

- Hollow Knight (Steam)
- Modding API instalada

## Instalação

Coloque a pasta `CreatureSpawner` (com o `CreatureSpawner.dll`) em:

`Hollow Knight\hollow_knight_Data\Managed\Mods\`

## Bom saber

- **O jogo demora mais para abrir.** O mod carrega todas as criaturas de uma vez na inicialização. Isso acontece só uma vez por sessão.
- Os chefes foram adaptados para lutar fora da sala original, mas alguns detalhes podem ficar diferentes do jogo.
- Se você achar algum bug, ele provavelmente é de uma criatura específica. Anote o nome dela e o que aconteceu.
